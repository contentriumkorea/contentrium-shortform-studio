# 콘텐츠리움 숏폼 스튜디오 0.3.1

Windows에서 원본 영상을 가져와 하이라이트를 고르고, 제목·음성 자막·화면 구도를 편집해 세로 영상으로 출력하는 설치형 프로그램입니다.

이 저장소는 **설치파일과 배포 안내 전용**입니다. 애플리케이션 소스, 사용자 영상, 계정 정보, 활성화 발급 키는 공개하지 않습니다.

## 설치

1. [최신 배포](https://github.com/contentriumkorea/contentrium-shortform-studio/releases/latest)에서 `ContentriumShortformStudio-Setup.exe`를 받습니다.
2. Windows 10/11 x64에서 설치파일을 실행합니다. 별도 Python 설치는 필요하지 않습니다.
3. 첫 설치에는 인터넷 연결이 필요합니다. 설치 과정에서 검증된 영상 엔진과, 없는 경우 Microsoft WebView2 Runtime을 준비합니다.
4. 프로그램 설정에서 관리자에게 받은 공통 비밀번호를 한 번 입력합니다. 활성화 상태가 유지되면 별도 코드를 입력할 필요가 없습니다.
5. 영상을 추가하고 분석한 뒤 **편집하기**를 누릅니다.

공통 비밀번호를 사용할 수 없거나 기존 설치를 이어야 할 때는 `기존 PC별 CS1 코드 사용` 접기를 이용할 수 있습니다. 이 경우 `PC 요청 정보 발급`에서 표시한 `device_request`만 관리자에게 전달해 PC별 코드를 요청합니다. 공통 비밀번호는 여러 PC가 공유할 수 있으므로, 이를 아는 사람의 활성화를 PC별로 구분하거나 즉시 회수하지 못합니다. 비밀번호 원문은 이 안내·소스·테스트·릴리스에 포함하지 않습니다.

설치파일은 현재 Windows 코드 서명 인증서로 서명되지 않았습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 표시될 수 있습니다. 보안 검사를 끄지 마세요. 배포 경로와 SHA-256을 확인하고 기관의 설치 정책을 따라야 합니다.

## 편집

- 내 영상 파일, YouTube 링크, 지원 웹페이지·팔로우 수집을 사용합니다. 공개 접근과 다운로드 권한이 있는 영상만 사용하세요. 사이트 접근 정책에 따라 수집이 제한될 수 있습니다.
- 왼쪽은 원본·템플릿·자막 목록, 가운데는 미리보기, 오른쪽은 선택 속성, 아래는 영상·제목·말 자막 타임라인입니다.
- 상단 제목과 말 자막은 독립적으로 수정합니다. 화면 맞춤·확대·위치, 상하 프레임, 자막 시각과 문구를 조절할 수 있습니다.
- 선택한 영상 구간 전체를 다시 음성 인식하고, 결과를 확인한 뒤 적용할 수 있습니다. 수정·삭제한 자막을 보호하는 병합과 명시적인 전체 교체를 구분합니다.
- 음성 인식은 사람 이름·기관명·배경 소음 등에서 오탈자나 누락이 생길 수 있습니다. 게시 전 영상을 끝까지 재생하며 자막을 확인하세요. 전체 구간 처리 완료는 모든 단어가 정확하다는 보장이 아닙니다.
- 플랫폼 안전 영역은 편집 가이드입니다. 앱 UI·기기·게시 위치에 따라 가려지는 영역이 달라질 수 있으므로 실제 게시 화면을 확인하세요.

## 로컬 AI와 Codex

음성 인식 모델은 설치파일에 포함됩니다. 로컬 AI 하이라이트 추천용 언어 모델은 설정에서 별도로 준비합니다. 이 모델의 첫 다운로드에는 추가 저장 공간과 인터넷이 필요합니다. 모델이 준비된 뒤 로컬 영상 분석·편집은 Codex 연결 없이 실행할 수 있습니다. 인터넷 영상 가져오기·팔로우 확인·업데이트 확인에는 네트워크가 필요합니다.

Codex 연결은 선택 사항이며 각 PC에서 본인의 계정으로 연결합니다. 이 프로그램에는 유료 API 키 모드가 없습니다.

## 업데이트와 데이터

설정에서 새 버전을 확인하고 서명·해시 검증된 설치파일을 내려받을 수 있습니다. **자동 설치·실패 시 자동 되돌리기는 아직 제공하지 않습니다.** 작업을 저장하고 프로그램을 종료·제거한 뒤 새 설치파일을 직접 실행합니다. 완성된 기존 설치본을 그대로 덮어쓰지는 않습니다.

0.3.0 사용자는 앱 내 업데이트 확인 대신 [0.3.1 릴리스 페이지](https://github.com/contentriumkorea/contentrium-shortform-studio/releases/latest)에서 새 설치파일을 직접 다운로드하고, 저장·종료·기존 프로그램 제거 후 재설치하세요. 사용자 영상·작업·설정 데이터는 보존됩니다.

영상·작업·설정은 `%LOCALAPPDATA%\ContentriumShortformStudio\data`에 보관되며 프로그램 제거 시 삭제하지 않습니다. 중요한 작업은 별도로 백업하세요. CS1 방식은 장치 변경 시 PC별 코드 재발급이 필요합니다. 공통 비밀번호 방식은 새 PC에서 관리자에게 다시 안내받아 입력할 수 있습니다.

## 검증 범위

0.3.0 기반 검증 기록에는 Python 경로가 없는 격리 실행 환경, 한글·공백 경로, 설치 부트스트랩, CPU 음성 감지·영상 인코딩과 제거 파일 목록·실행 중 잠금 확인이 포함됩니다. 0.3.1은 Python 테스트 547개, 설정·편집 상태 테스트 29개, 실제 설정 UI/API와 Windows DPAPI 활성화 유지 검증을 통과했습니다. 최종 번들 감사, 업데이트 정보의 서명 검증, GitHub에서 실제 내려받은 설치파일의 크기·SHA-256 대조도 완료했습니다. 완전히 새로운 Windows PC·VM, 이 버전의 전체 설치·제거 및 모든 GPU 조합은 아직 별도 검증이 필요합니다. 문제 발생 시 설정의 준비 상태와 로그를 확인해 주세요.

프로그램 및 함께 제공되는 구성요소의 이용 조건은 설치 폴더의 `THIRD_PARTY_NOTICES.txt`와 `third_party_licenses`를 참고하세요. CapCut, YouTube, Instagram 또는 영상 제공 기관의 공식 제품이 아닙니다.

소스 코드와 활성화·업데이트 발급용 비밀키는 공개하지 않으며 공개 설치 저장소에도 포함하지 않습니다. 개발 실행은 배포용 활성화 완료를 의미하지 않습니다. Windows Authenticode 서명이 없으면 SmartScreen 또는 알 수 없는 게시자 경고가 표시될 수 있습니다.
