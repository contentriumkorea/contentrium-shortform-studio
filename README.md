# 콘텐츠리움 숏폼 스튜디오 0.3.3

Windows에서 원본 영상을 가져와 하이라이트를 고르고, 제목·음성 자막·화면 구도를 편집해 세로 영상으로 출력하는 설치형 프로그램입니다.

이 저장소는 **설치파일과 배포 안내 전용**입니다. 애플리케이션 소스, 사용자 영상, 계정 정보, 활성화 발급 키는 공개하지 않습니다.

## 0.3.3 변경 사항

- FFmpeg 9에서 지원이 제거된 `-vsync` 옵션을 `-fps_mode` 기반 호출로 교체해 영상 처리 호환성을 보완했습니다.
- 시작 준비 점검에서 영상 처리·장면 분석과 로컬 음성 분석 준비 상태를 확인하고 결과를 안내합니다.
- 작업 상세에서 안전하게 필터링된 오류 원인, 실패 단계·시각, 다음 조치, 기술 세부사항과 최근 작업 기록을 확인할 수 있습니다.
- 작업별 진단 복사·JSON 저장과 설정의 접이식 `오류·진단 기록` 및 최근 50건 조회를 제공합니다.
- 진단은 민감정보를 필터링하며 원본 영상·음성·전사·계정 파일과 원문 오류 기록을 포함하지 않습니다. 복사·JSON 저장은 안전하게 정리된 진단 필드만 대상으로 하고 자동으로 외부 전송하지 않습니다.
- 이전 버전의 기록은 실패 단계나 앱 버전이 `기록되지 않음`으로 표시될 수 있습니다.

## 설치

1. [최신 배포](https://github.com/contentriumkorea/contentrium-shortform-studio/releases/latest)에서 `ContentriumShortformStudio-Setup.exe`를 받습니다.
2. Windows 10/11 x64에서 설치파일을 실행합니다. 별도 Python 설치는 필요하지 않습니다.
3. 첫 설치에는 인터넷 연결이 필요합니다. 설치 과정에서 검증된 영상 엔진과, 없는 경우 Microsoft WebView2 Runtime을 준비합니다.
4. 프로그램 설정에서 관리자에게 받은 공통 비밀번호를 한 번 입력합니다. 활성화 상태가 유지되면 별도 코드를 입력할 필요가 없습니다.
5. 영상을 추가하고 분석한 뒤 **편집하기**를 누릅니다.

공통 비밀번호를 사용할 수 없거나 기존 설치를 이어야 할 때는 `기존 PC별 CS1 코드 사용` 접기를 이용할 수 있습니다. 이 경우 `PC 요청 정보 발급`에서 표시한 `device_request`만 관리자에게 전달해 PC별 코드를 요청합니다. 공통 비밀번호는 여러 PC가 공유할 수 있으므로, 이를 아는 사람의 활성화를 PC별로 구분하거나 즉시 회수하지 못합니다. 비밀번호 원문은 이 안내·소스·테스트·릴리스에 포함하지 않습니다.

설치파일은 현재 Windows 코드 서명 인증서로 서명되지 않았습니다. Windows에서 알 수 없는 게시자 또는 SmartScreen 경고가 표시될 수 있습니다. 보안 검사를 끄지 마세요. 배포 경로와 SHA-256을 확인하고 기관의 설치 정책을 따라야 합니다.

## 편집

- 내 영상 파일, YouTube 링크, 지원 웹페이지·팔로우 수집을 사용합니다. 공개 접근과 다운로드 권한이 있는 영상만 사용하세요. 사이트 접근 정책에 따라 수집이 제한될 수 있습니다.
- 왼쪽은 원본·템플릿·자막 목록, 가운데는 미리보기, 오른쪽은 선택 속성, 아래는 영상·제목·말 자막 타임라인입니다.
- 상단 제목과 말 자막은 독립적으로 수정합니다. 화면 맞춤·확대·위치, 상하 프레임, 자막 시각과 문구를 조절할 수 있습니다.
- 선택한 영상 구간 전체를 다시 음성 인식하고, 결과를 확인한 뒤 적용할 수 있습니다. 수정·삭제한 자막을 보호하는 병합과 명시적인 전체 교체를 구분합니다.
- 음성 인식은 사람 이름·기관명·배경 소음 등에서 오탈자나 누락이 생길 수 있습니다. 게시 전 영상을 끝까지 재생하며 자막을 확인하세요. 전체 구간 처리 완료는 모든 단어가 정확하다는 보장이 아닙니다.
- 플랫폼 안전 영역은 편집 가이드입니다. 앱 UI·기기·게시 위치에 따라 가려지는 영역이 달라질 수 있으므로 실제 게시 화면을 확인하세요.

## 로컬 AI와 Codex

음성 인식 모델은 설치파일에 포함됩니다. 로컬 AI 하이라이트 추천용 언어 모델은 설정에서 별도로 준비합니다. 이 모델의 첫 다운로드에는 추가 저장 공간과 인터넷이 필요합니다. 모델이 준비된 뒤 로컬 영상 분석·편집은 Codex 연결 없이 실행할 수 있습니다. 인터넷 영상 가져오기·팔로우 확인·업데이트 확인에는 네트워크가 필요합니다.

Codex 연결은 선택 사항이며 각 PC에서 본인의 계정으로 연결합니다. 이 프로그램에는 유료 API 키 모드가 없습니다.

## 게시판·채널 수집

기본 등록 출처는 없습니다. 팔로우에 게시판·채널을 직접 등록하면 지원되는 목록의 과거 영상 정보부터 가져옵니다. 원본 영상 파일은 선택해서 내려받으며, 자동 후보 생성을 켜면 다운로드·분석도 수행하므로 시간과 저장 공간이 필요합니다.

출처마다 페이지 진행, 수집 건수, 마지막 확인 시각, 실제 자료 추가 시각, 전체 확인 성공 시각을 구분합니다. 실패·중단한 수집은 저장된 위치에서 재개할 수 있고, `전체 다시 가져오기`로 과거 목록을 다시 확인할 수 있습니다. 같은 영상은 중복 등록하지 않습니다. 라이브러리는 페이지 이동과 전체 자료 검색을 지원합니다.

경북 영상기록, YouTube 채널·재생목록과 명시적인 게시글·다음 페이지 링크가 있는 일부 웹 게시판을 지원합니다. 로그인·동적 더보기·사이트 전용 플레이어 등 전체 범위를 확인할 수 없는 사이트는 별도 지원이 필요합니다. 모든 게시판의 모든 파일을 가져오는 범용 웹 복제 프로그램은 아닙니다. 구버전의 자동 등록 경북 출처는 제거하되 이미 가져온 영상과 작업은 보존합니다. 필요하면 해당 출처를 직접 다시 등록하세요.

## 저장 공간 관리

설정의 `저장 공간`에서 현재 경로, 폴더별 사용량과 디스크 여유 공간을 확인하고 폴더를 열 수 있습니다. `저장 위치 변경`에서 비어 있는 로컬 폴더를 선택하고 복사에 동의한 뒤 변경을 예약합니다. 작업을 저장하고 앱을 완전히 종료·재실행하면 데이터를 검증해 복사한 뒤 새 경로로 전환합니다. 데이터가 많으면 다음 실행 준비에 시간이 걸립니다.

선택한 폴더 아래 `data`에는 원본·작업 파일·미리보기·완성본·설정, `engines`에는 앱에서 내려받은 로컬 AI 모델을 보관합니다. 설치 파일, 직접 연결한 외부 모델과 Codex 계정 폴더는 옮기지 않습니다. 지정 경로는 Windows 사용자별로 유지됩니다.

원래 자료는 자동 삭제하지 않습니다. 복사에 실패하거나 중단되면 기존 저장 위치로 시작하고 자동 재복사를 중지합니다. 설정에 표시되는 보존된 복사본을 확인한 뒤 변경 예약을 취소하고 새 폴더로 다시 예약하세요. 지정 드라이브가 분리되면 다시 연결해야 하며, 네트워크 공유 폴더·정션은 지원하지 않습니다. 사용 중인 원본이나 작업 파일을 직접 삭제하면 편집을 이어갈 수 없으니 중요한 자료는 별도로 백업하세요.

## 업데이트와 데이터

설정에서 새 버전을 확인하고 서명·해시 검증된 설치파일을 내려받을 수 있습니다. **자동 설치·실패 시 자동 되돌리기는 아직 제공하지 않습니다.** 작업을 저장하고 프로그램을 종료·제거한 뒤 새 설치파일을 직접 실행합니다. 완성된 기존 설치본을 그대로 덮어쓰지는 않습니다.

0.3.0 사용자는 앱 내 업데이트 확인 대신 [최신 릴리스 페이지](https://github.com/contentriumkorea/contentrium-shortform-studio/releases/latest)에서 새 설치파일을 직접 다운로드하고, 저장·종료·기존 프로그램 제거 후 재설치하세요. 사용자 영상·작업·설정 데이터는 보존됩니다.

영상·작업·설정의 기본 위치는 `%LOCALAPPDATA%\ContentriumShortformStudio\data`이며, 변경한 경우 지정 저장 공간의 `data`를 사용합니다. 프로그램 제거 시 이 자료와 저장 위치 설정을 삭제하지 않습니다. CS1 방식은 장치 변경 시 PC별 코드 재발급이 필요합니다. 공통 비밀번호 방식은 새 PC에서 관리자에게 다시 안내받아 입력할 수 있습니다.

## 검증 범위

0.3.3 변경분은 시작 준비 점검의 영상 처리·장면 분석과 로컬 음성 분석 상태, FFmpeg 9 호환 호출, 작업 오류 상세·최근 진단 기록·안전한 복사·JSON 저장 흐름을 확인하는 범위에서 검증했습니다. 93.594초 테스트 원본에서 CPU 음성인식 전사 20개와 30초 후보 3개를 생성했고, 세 후보 모두 품질 검사를 통과했으며 원본 보존을 확인했습니다.

최종 Python 자동 테스트 632개와 JavaScript 테스트 35개를 통과했습니다. 위 실제 원본 검증은 수정된 소스, 배포 엔진, 포장 WAV shim을 분리한 환경에서 수행했습니다. 실제 EXE에 포함된 분석 코드의 장면 추출과 진단 필터도 별도로 검사했습니다. 완전히 새로운 Windows PC·VM 검증 결과는 아니며 모든 GPU 조합은 별도 검증이 필요합니다. 설치파일의 SHA-256과 상세 검증 결과는 릴리스 안내를 참고하세요.

프로그램 및 함께 제공되는 구성요소의 이용 조건은 설치 폴더의 `THIRD_PARTY_NOTICES.txt`와 `third_party_licenses`를 참고하세요. CapCut, YouTube, Instagram 또는 영상 제공 기관의 공식 제품이 아닙니다.

소스 코드와 활성화·업데이트 발급용 비밀키는 공개하지 않으며 공개 설치 저장소에도 포함하지 않습니다. 개발 실행은 배포용 활성화 완료를 의미하지 않습니다. Windows Authenticode 서명이 없으면 SmartScreen 또는 알 수 없는 게시자 경고가 표시될 수 있습니다.
